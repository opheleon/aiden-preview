# Live-provider example

`codex-live.json` and `codex-live.md` were generated by a real Codex subscription run against two **synthetic disposable repositories**. They are not reports about Opheleon or any user's real project.

The source fixture contains a frontend calling `/books`, a backend serving `/items`, and no book-creation flow. See `tests/helpers.ts` and `scripts/live-smoke.ts` to reproduce. Generated IDs and commit hashes belong to that disposable run; the CLI validates actual runs using their locally recorded snapshots and read receipts, not this exported example alone.
